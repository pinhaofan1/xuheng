# 0.3.0 界面设计记录

用户选择：简洁专业、浅色、清晰布局，接近成熟写作工具。

对象是进行长篇创作与修订的作者。作品库负责找到作品并继续操作；编辑器负责写作；审校负责对照原文和依据。品牌只占小面积，不再让装饰舞台压过实际内容。

| 设计项 | 取值与用途 |
| --- | --- |
| 画布 | `#F7F8FB`，连续工作区 |
| 面板 | `#FFFFFF`，稿件与操作区域 |
| 正文 | `#263246`，标题和界面文字 |
| 次要文字 | `#718096`，时间、进度和说明 |
| 主要操作 | `#4564CF`，导航选中和主要按钮 |
| 证据 | `#27847E`，选中提示与来源；原文用浅黄色高亮 |
| 界面字体 | Microsoft YaHei / PingFang SC / 系统无衬线 |
| 正文字体 | STSong / SimSun 等本机宋体，不依赖字体 CDN |

作品库采用固定导航加卡片，审校采用固定导航加正文/结果两栏；设置按需打开。它的识别点是原文中的高亮与右侧依据成对出现，让用户知道一条提示从何而来，而不是增加图案或展示虚构统计。

检查包括生产构建、浏览器功能测试、桌面及手机截图、横向溢出、键盘焦点和减少动态效果偏好。未统一重写全部上游复杂面板，知识图谱与托管驾驶舱仍需后续专项打磨。

## 编辑桌更新

作品库使用纸色底、墨绿操作和宋体标题。作品按稿件目录纵向排列，章数、字数、创作与审校入口与书名对齐。原来的统计卡合成一行，删除了作品库底部重复介绍。章节编辑加宽稿件内边距，审校沿用原文与证据两栏，窄屏按阅读顺序纵向排列。

- Edge 实拍自查覆盖桌面作品库、章节编辑和审校，以及 390px 的作品库与审校、320px 的搜索无结果状态和 390px 深色作品库。
- 隔离环境使用已提交的后端与本轮前端生产构建。5 项浏览器回归通过，覆盖作品搜索、创作导航、规则与模拟 AI 审校、引用高亮、反馈持久化、人物事实及历史检索。另检查新建弹窗、从作品库直达审校及窄屏无页面横向溢出。
