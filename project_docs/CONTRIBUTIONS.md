# 模块与来源

## 叙衡功能模块

| 模块 | 实现 |
| --- | --- |
| 主体归属 | 多人句子中的动作归属、明确限制、别名和歧义处理 |
| 证据与反馈 | Unicode 原文范围、来源快照、版本失效、确认/忽略/撤销及并发更新检查 |
| 混合检索 | 同作品前章 BM25 与向量召回、RRF、模型重排、索引与缓存 |
| AI 审校 | 有界兼容接口、结构及逐字引用验证、无效证据警告与实际用量 |
| 人物事实 | 通用事实配置、作品人物导入草稿、旧规则哈希兼容 |
| 任务与报告 | 后台进度、活动任务复用、取消、运行历史及 JSON 导出 |
| 产品界面 | 浅色作品库、统一导航、正文/结果两栏、设置抽屉及移动适配 |
| 集成修复 | 保存接口、角色保留、提示词契约、变量快照和输出预算 |

## 来源组件
