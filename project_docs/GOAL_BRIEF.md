# 叙衡剩余目标实施契约

基线：0.10.0，提交 `5d2bc986`；用户批准日期：2026-11-05。面向 Python 后端 / AI 应用开发简历和本机演示。本文保存已批准计划的实施内容与验收条件；运行进度见 GOAL_PROGRESS.md，完成状态仍以 DEVELOPMENT_PROGRESS.json 为准。

## 约束

沿用 Python、FastAPI、SQLite、Vue 和已有模型接口；保持 API 兼容，不新增依赖，不重构无关代码。前端采用简洁浅色专业写作软件风格。保留用户修改、作品、配置、许可和必要版权声明。不创建 ADR，不强推或改写 Git 历史。不得提交凭据、用户数据库、日志或私人备份。

迁移前创建联合备份；付费长跑、故障注入和恢复仅作用于隔离数据。旧作品首次打开只标记缺失索引，不自动触发全书付费构建。测试不得删除、跳过、弱化或缩窄以冒充通过。不能将模拟场景、AI 自评和本机测试冒充真实模型、独立人工标注或跨平台 CI 验收。

## 接口与数据

- 作品 API 增加 `/novels/{id}/index` 状态以及任务创建、取消、继续，返回任务 ID。任务及索引元数据在主库，纳入联合备份；以作品、章节、正文哈希、模型指纹和恢复代次识别版本。
- 远端模型调用不持写事务，保存结果前复核正文版本；过期、删除、跨书和未来片段禁止进入结果。默认6个正文片段，重排最多24个候选；跨目标章节的摘要禁用，摘要仅定位正文。
- 事实查询、冲突处理和撤销，以及人物重命名、合并预览/提交均限定作品；修改带版本及幂等请求 ID，冲突返回409，前端保留选择。当前数据事务更新，历史快照不可变。
- 复用既有任务、预算、模型结果和恢复记录，不另建独立费用账本；新表增量迁移，普通调用保持兼容。

## 预算

同一目标累计最多人民币20元，不因重启、换书或批次重置：校准2元；十章托管12元；Embedding/Reranker联调3元；后续真实复测3元。调用前核对官方单价，按现有账本累计实际计价和在途预留。无法计价、达到阶段或总限额、服务异常及结果未知时停止对应调用，保留缺口并继续离线工作；不追加预算、不自动重发可能已计费请求。服务商实际账单为最终依据，本地预算不保证服务商不会多计费。
